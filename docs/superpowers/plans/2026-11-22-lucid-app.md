# Lucid Menu-Bar App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `Lucid.app`: hold a key, speak, release, and cleaned text appears at the cursor in any app.

**Architecture:** A new executable target, `Lucid`, built on the libraries from the earlier plans. It is a thin layer: an event tap feeds key events to `DictationMachine`, `AVAudioEngine` supplies audio, `EngineSupervisor` and `Pipeline` turn it into text, and the text is pasted at the cursor. A script wraps the binary in an app bundle so macOS can grant it microphone and Accessibility access.

**Tech Stack:** Swift 5.9, AppKit, SwiftUI, AVFoundation, ApplicationServices (Accessibility and event taps), Carbon (secure-input check), IOKit.

This is plan 3b. Plan 3a built the logic it depends on. Plan 3c adds the settings, history and onboarding windows.

Spec: [`docs/superpowers/specs/2026-11-22-lucid-dictation-design.md`](../specs/2026-11-22-lucid-dictation-design.md)

## Global Constraints

- Swift tools version 5.9, macOS 14 minimum, no Swift package dependencies.
- The app builds with `swift build` alone. Xcode is not installed.
- Bundle identifier: `com.siliconspider.lucid`. The app is a menu-bar agent (`LSUIElement`), with no Dock icon.
- The pill never takes keyboard focus and never receives clicks. If it did, the paste would go to the wrong place.
- Nothing dictated is written to a log.
- The cleanup model is named in full, "S1-mini by Superwhisper", wherever a user sees it.
- Every task ends with a commit pushed to `main` on `origin`.
- Every commit message ends with the line `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

## What can and cannot be checked automatically

The hotkey, the microphone and pasting all need permissions that only the person at the Mac can grant, so no script can exercise them. This plan checks what it can and is explicit about the rest.

| Checked by | What |
|---|---|
| `scripts/test.sh` | The logic from plans 1 to 3a. Already passing. |
| `swift build` | Every line of the app compiles. |
| `Lucid --self-test <wav>` | The app's own settings, engine start-up and pipeline, with no UI. |
| `Lucid --render-ui <folder>` | The pill is drawn to PNG files, which are then looked at. |
| Launching the bundle | The app starts, stays running, and starts its engines. |
| `Lucid --dump-menu` | The menu is built and printed as text, which shows its status line and items for the current state. Added while building Task 4. |
| **A person, by hand** | The hotkey, recording, the pill on screen, and pasting. The checklist is in Task 4. |

```swift
import Foundation
import IOKit.ps
import LucidCore

enum SystemInfo {
    /// True on a Mac with a built-in battery, which also means a built-in keyboard with an Fn key.
    static var isLaptop: Bool {
        guard let info = IOPSCopyPowerSourcesInfo()?.takeRetainedValue(),
              let list = IOPSCopyPowerSourcesList(info)?.takeRetainedValue() else { return false }
        for source in list as [AnyObject] {
            guard let details = IOPSGetPowerSourceDescription(info, source)?.takeUnretainedValue()
                    as? [String: Any] else { continue }
            if details[kIOPSTypeKey] as? String == kIOPSInternalBatteryType { return true }
        }
        return false
    }

    static var defaultHotkey: HotkeyChoice {
        HotkeyChoice.standard(forModelName: isLaptop ? "MacBook" : "Mac")
    }

    static var appVersion: String {
        Bundle.main.object(forInfoDictionaryKey: "CFBundleShortVersionString") as? String ?? "development build"
    }
}
```

```swift
    private enum Key {
        static let hotkey = "hotkey"
        static let level = "cleanupLevel"
        static let keepRecordings = "keepRecordings"
        static let onboardingDone = "onboardingDone"
    }

    private let defaults: UserDefaults

    @Published var hotkey: HotkeyChoice {
        didSet { defaults.set(hotkey.rawValue, forKey: Key.hotkey) }
    }

    @Published var level: CleanupLevel {
        didSet { defaults.set(level.rawValue, forKey: Key.level) }
    }

    /// Whether the audio of recent dictations is kept, so a failed one can be retried.
    @Published var keepRecordings: Bool {
        didSet { defaults.set(keepRecordings, forKey: Key.keepRecordings) }
    }

    @Published var onboardingDone: Bool {
        didSet { defaults.set(onboardingDone, forKey: Key.onboardingDone) }
    }

    init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
        hotkey = defaults.string(forKey: Key.hotkey).flatMap(HotkeyChoice.init(rawValue:)) ?? SystemInfo.defaultHotkey
        level = defaults.string(forKey: Key.level).flatMap(CleanupLevel.init(rawValue:)) ?? .light
        keepRecordings = defaults.object(forKey: Key.keepRecordings) as? Bool ?? true
        onboardingDone = defaults.bool(forKey: Key.onboardingDone)
    }

    /// Not tied to the main actor, so it can be a default argument anywhere.
    nonisolated static var dictionaryURL: URL {
        EngineConfig.supportDirectory.appendingPathComponent("dictionary.json")
    }
}
```

**File:** `Sources/Lucid/EngineManager.swift`

```swift
import Foundation
import LucidCore
import LucidEngines

/// What one dictation produced.
struct DictationOutcome {
    /// The transcript exactly as the speech engine heard it.
    let heard: String
    let speechMillis: Int
    let result: PipelineResult
}

/// Owns the engines for the app, and runs a recording through them.
@MainActor
final class EngineManager: ObservableObject {
    enum Status: Equatable {
        case starting
        case ready
        /// Engines or models are not installed. The strings say what is missing.
        case setupNeeded([String])
        case failed(String)
    }

    @Published private(set) var status: Status = .starting

    private let tracksProcesses: Bool
    private var cleanupModel: CleanupModel
    private var supervisor: EngineSupervisor

    /// `tracksProcesses` is false for the self-test, so it never stops a running app's engines.
    init(level: CleanupLevel, tracksProcesses: Bool = true) {
        self.tracksProcesses = tracksProcesses
        cleanupModel = Self.model(for: level)
        supervisor = EngineSupervisor(config: .standard(cleanup: cleanupModel), tracksProcesses: tracksProcesses)
    }

    /// True when the optional general model, used for the Medium level, has been downloaded.
    static var generalModelInstalled: Bool {
        FileManager.default.fileExists(atPath: EngineConfig.standard(cleanup: EngineConfig.general).cleanupModelURL.path)
    }

    /// Medium needs the general model. Everything else uses S1-mini by Superwhisper.
    static func model(for level: CleanupLevel) -> CleanupModel {
        level == .medium && generalModelInstalled ? EngineConfig.general : EngineConfig.s1Mini
    }

    func start() async {
        status = .starting
        let missing = EngineConfig.standard(cleanup: cleanupModel).missing()
        guard missing.isEmpty else {
            status = .setupNeeded(missing)
            return
        }
        do {
            try await supervisor.start()
            status = .ready
        } catch {
            status = .failed("\(error)")
        }
    }

    /// Swaps the cleanup model if the new level needs a different one.
    func setLevel(_ level: CleanupLevel) async {
        let wanted = Self.model(for: level)
        guard wanted != cleanupModel else { return }
        cleanupModel = wanted
        await supervisor.stop()
        supervisor = EngineSupervisor(config: .standard(cleanup: wanted), tracksProcesses: tracksProcesses)
        await start()
    }

    func stop() async {
        await supervisor.stop()
    }

    /// Stops the engines and waits, for use while the app is quitting.
    func stopNow() {
        let supervisor = supervisor
        let done = DispatchSemaphore(value: 0)
        Task.detached {
            await supervisor.stop()
            done.signal()
        }
        _ = done.wait(timeout: .now() + 4)
    }

    /// Turns a recording into cleaned text. Restarts an engine first if one has stopped.
    func dictate(wav: Data, context: PipelineContext) async throws -> DictationOutcome {
        try await supervisor.recover()
        let transcriber = try await supervisor.transcriber()
        let began = Date()
        let heard = try await transcriber.transcribe(wav: wav, prompt: context.dictionary.recognitionPrompt())
        let speechMillis = Int(Date().timeIntervalSince(began) * 1000)

        // A missing cleanup engine is not fatal: the rules stage still runs.
        let cleaner: LlamaClient? = context.level == .off ? nil : try? await supervisor.cleaner()
        let result = await Pipeline(cleaner: cleaner).process(heard, context: context)
        return DictationOutcome(heard: heard, speechMillis: speechMillis, result: result)
    }
}
```

**File:** `Sources/Lucid/SelfTest.swift`

```swift
import Foundation
import LucidCore
import LucidEngines

/// Runs the app's own settings, engines and pipeline on audio files, with no UI.
/// Used to check a build without a keyboard or a microphone.
enum SelfTest {
    @MainActor
    static func run(files: [String]) async -> Int32 {
        guard !files.isEmpty else {
            print("usage: Lucid --self-test <file.wav>...")
            return 2
        }
        let settings = AppSettings()
        let engines = EngineManager(level: settings.level, tracksProcesses: false)
        await engines.start()
        guard engines.status == .ready else {
            print("engines are not ready: \(engines.status)")
            return 1
        }
        print("engines ready. level: \(settings.level.rawValue). dictation key: \(settings.hotkey.title).")

        let dictionary = (try? PersonalDictionary.load(from: AppSettings.dictionaryURL)) ?? .empty
        let context = PipelineContext(level: settings.level, dictionary: dictionary)
        var status: Int32 = 0
        for path in files {
            do {
                let wav = try Data(contentsOf: URL(fileURLWithPath: path))
                let outcome = try await engines.dictate(wav: wav, context: context)
                let total = outcome.speechMillis + outcome.result.cleanMillis
                print("\(URL(fileURLWithPath: path).lastPathComponent): \(total) ms")
                print("  heard:   \(outcome.heard)")
                print("  cleaned: \(outcome.result.finalText)")
            } catch {
                print("error: \(path): \(error)")
                status = 1
            }
        }
        await engines.stop()
        return status
    }
}
```

```swift
import AppKit
import SwiftUI

enum PillState: Equatable {
    case hidden
    case recording
    case handsFree
    case processing
    case message(String)
}

@MainActor
final class PillModel: ObservableObject {
    @Published var state: PillState = .hidden
    /// The microphone level, where speech is roughly 0.02 to 0.2.
    @Published var level: Float = 0
    @Published var pulsing = false
}

/// The on-screen indicator: a small dark capsule.
struct PillView: View {
    @ObservedObject var model: PillModel

    var body: some View {
        HStack(spacing: 9) {
            content
        }
        .font(.system(size: 12, weight: .medium))
        .foregroundStyle(.white)
        .padding(.horizontal, 15)
        .frame(height: 34)
        .background(Capsule().fill(Color.black.opacity(0.84)))
        .overlay(Capsule().strokeBorder(Color.white.opacity(0.16), lineWidth: 1))
        .scaleEffect(model.pulsing ? 1.08 : 1)
        .animation(.easeOut(duration: 0.15), value: model.pulsing)
        .fixedSize()
    }

    @ViewBuilder
    private var content: some View {
        switch model.state {
        case .hidden:
            EmptyView()
        case .recording:
            LevelBars(level: model.level)
        case .handsFree:
            LevelBars(level: model.level)
            Text("Hands-free. Press the key again to finish.")
        case .processing:
            ProcessingDots()
        case .message(let text):
            Text(text)
        }
    }
}

/// Five bars that grow with the microphone level. The middle bar is the tallest.
private struct LevelBars: View {
    let level: Float
    private let weights: [CGFloat] = [0.45, 0.75, 1.0, 0.75, 0.45]

    var body: some View {
        let strength = min(1, CGFloat(level) * 9)
        HStack(spacing: 3) {
            ForEach(weights.indices, id: \.self) { index in
                Capsule()
                    .fill(Color.white)
                    .frame(width: 3, height: 4 + 16 * strength * weights[index])
            }
        }
        .frame(height: 22)
        .animation(.linear(duration: 0.08), value: level)
    }
}

/// Three dots that brighten in turn.
private struct ProcessingDots: View {
    var body: some View {
        TimelineView(.periodic(from: .now, by: 0.25)) { timeline in
            let step = Int(timeline.date.timeIntervalSinceReferenceDate / 0.25) % 3
            HStack(spacing: 5) {
                ForEach(0..<3, id: \.self) { index in
                    Circle()
                        .fill(Color.white.opacity(index == step ? 1 : 0.35))
                        .frame(width: 6, height: 6)
                }
            }
        }
        .frame(height: 22)
    }
}

/// Owns the pill's window and decides where and when it shows.
@MainActor
final class PillController {
    let model = PillModel()
    private let panel: NSPanel
    private var pendingHide: DispatchWorkItem?
    private static let size = NSSize(width: 420, height: 60)

    init() {
        panel = NSPanel(
            contentRect: NSRect(origin: .zero, size: Self.size),
            styleMask: [.borderless, .nonactivatingPanel],
            backing: .buffered,
            defer: true
        )
        panel.isOpaque = false
        panel.backgroundColor = .clear
        panel.hasShadow = false
        panel.level = .statusBar
        panel.hidesOnDeactivate = false
        // The pill must never take focus or a click, or the paste would go to the wrong place.
        panel.ignoresMouseEvents = true
        panel.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]
        panel.contentView = NSHostingView(
            rootView: PillView(model: model).frame(width: Self.size.width, height: Self.size.height)
        )
    }

    func show(_ state: PillState) {
        pendingHide?.cancel()
        model.state = state
        if state == .hidden {
            panel.orderOut(nil)
            return
        }
        position()
        panel.orderFrontRegardless()
    }

    func hide() {
        show(.hidden)
    }

    /// Shows a short message, then hides.
    func flash(_ text: String, seconds: TimeInterval = 2.2) {
        show(.message(text))
        let work = DispatchWorkItem { [weak self] in self?.hide() }
        pendingHide = work
        DispatchQueue.main.asyncAfter(deadline: .now() + seconds, execute: work)
    }

    /// A brief bump, to acknowledge a key press that cannot be acted on yet.
    func pulse() {
        model.pulsing = true
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.15) { [weak self] in
            self?.model.pulsing = false
        }
    }

    func setLevel(_ level: Float) {
        model.level = level
    }

    /// Bottom centre of the screen that holds the mouse pointer, clear of the Dock.
    private func position() {
        let mouse = NSEvent.mouseLocation
        let screen = NSScreen.screens.first { NSMouseInRect(mouse, $0.frame, false) } ?? NSScreen.main
        guard let visible = screen?.visibleFrame else { return }
        panel.setFrameOrigin(NSPoint(x: visible.midX - Self.size.width / 2, y: visible.minY + 24))
    }
}
```

```swift
import AppKit
import SwiftUI

/// Draws the app's views to PNG files, so they can be looked at without running the app.
enum UIRenderer {
    @MainActor
    static func render(into folder: URL) -> Int32 {
        _ = NSApplication.shared
        do {
            try FileManager.default.createDirectory(at: folder, withIntermediateDirectories: true)
            for (name, view) in pillViews() {
                try write(view, to: folder.appendingPathComponent("\(name).png"))
                print("wrote \(name).png")
            }
            return 0
        } catch {
            print("error: \(error)")
            return 1
        }
    }

    @MainActor
    private static func pillViews() -> [(String, AnyView)] {
        func pill(_ state: PillState, level: Float = 0) -> AnyView {
            let model = PillModel()
            model.state = state
            model.level = level
            // A mid-grey backdrop shows the pill's edge the way a real desktop would.
            return AnyView(
                PillView(model: model)
                    .padding(20)
                    .background(Color(white: 0.55))
            )
        }
        return [
            ("pill-recording-quiet", pill(.recording, level: 0.01)),
            ("pill-recording-loud", pill(.recording, level: 0.12)),
            ("pill-hands-free", pill(.handsFree, level: 0.06)),
            ("pill-processing", pill(.processing)),
            ("pill-message", pill(.message("Copied. Press ⌘V"))),
        ]
    }

    @MainActor
    static func write(_ view: AnyView, to url: URL) throws {
        let hosting = NSHostingView(rootView: view)
```

### Task 3: Permissions, hotkey, recorder and inserter

The four pieces that touch macOS directly. None can be unit-tested, so each is kept small, and the decisions they depend on (the state machine, the insertion rules, the speech gate) are already tested in `LucidCore`.

**Files:**
- Create: `Sources/Lucid/Permissions.swift`, `Sources/Lucid/HotkeyMonitor.swift`, `Sources/Lucid/AudioRecorder.swift`, `Sources/Lucid/TextInserter.swift`

**Interfaces:**
- Consumes: `HotkeyChoice` from plan 3a.
- Produces:
  - `enum Permissions` with `microphone`, `requestMicrophone()`, `accessibility`, `promptForAccessibility()`, `openAccessibilitySettings()`, `openMicrophoneSettings()`, `openKeyboardSettings()`, `fnKeyConflicts`
  - `final class HotkeyMonitor` with `init(hotkey: HotkeyChoice)`, `var hotkey`, `var onSignal: ((Signal) -> Bool)?`, `func start() -> Bool`, `func stop()`, `var isRunning: Bool`, and `enum Signal { case hotkeyDown, hotkeyUp, otherKeyDown, escape }`

  - `enum TextInserter` with `static func captureTarget() -> InsertionTarget`, `@discardableResult static func insert(_ text: String, into target: InsertionTarget) -> Bool`, `static func copy(_ text: String)`

Design notes:

- **Hotkey.** An event tap on the main run loop watches modifier changes and key presses. It is an active tap, so Escape can be kept from the app underneath while a recording is being cancelled. Every other event is passed through untouched. macOS disables a tap that is slow to answer, so the tap re-enables itself when told it was disabled.
- **Recorder.** A new `AVAudioEngine` is made for each recording. That avoids stale state when the user changes microphone between dictations. Audio is converted to 16 kHz mono as it arrives.
- **Inserter.** The text is put on the clipboard, Command-V is posted, and the previous clipboard is put back 0.6 s later unless the user has copied something else in the meantime. The clipboard entry is marked transient so clipboard managers ignore it.
- **Where not to paste.** A password field, and a focused control that is clearly not a text field, such as a button. The text is left on the clipboard instead. When the Accessibility API cannot tell, Lucid pastes.

```swift
import AppKit
import LucidCore

extension HotkeyChoice {
    /// The modifier flag that is set while this key is down.
    var flag: CGEventFlags {
        switch self {
        case .fn: return .maskSecondaryFn
        case .rightOption: return .maskAlternate
        case .rightCommand: return .maskCommand
        }
    }
}

/// Watches the keyboard through an event tap and reports what the dictation machine needs.
final class HotkeyMonitor {
    enum Signal {
        case hotkeyDown
        case hotkeyUp
        /// Any key other than the hotkey and Escape went down.
        case otherKeyDown
        case escape
    }

    var hotkey: HotkeyChoice {
        didSet { isDown = false }
    }

    /// Called on the main thread. Return true to keep an Escape press from other apps.
    var onSignal: ((Signal) -> Bool)?

    private var tap: CFMachPort?
    private var source: CFRunLoopSource?
    private var isDown = false
    private static let escapeKey = 53

    init(hotkey: HotkeyChoice) {
        self.hotkey = hotkey
    }

    var isRunning: Bool { tap != nil }

    /// Starts watching. Returns false when macOS has not granted Accessibility access.
    func start() -> Bool {
        if tap != nil { return true }
        let mask = (1 << CGEventType.flagsChanged.rawValue) | (1 << CGEventType.keyDown.rawValue)
        guard let tap = CGEvent.tapCreate(
            tap: .cgSessionEventTap,
            place: .headInsertEventTap,
            options: .defaultTap,
            eventsOfInterest: CGEventMask(mask),
            callback: hotkeyTapCallback,
            userInfo: Unmanaged.passUnretained(self).toOpaque()
        ) else { return false }

        let source = CFMachPortCreateRunLoopSource(kCFAllocatorDefault, tap, 0)
        CFRunLoopAddSource(CFRunLoopGetMain(), source, .commonModes)
        CGEvent.tapEnable(tap: tap, enable: true)
        self.tap = tap
        self.source = source
        return true
    }

    func stop() {
        if let tap { CGEvent.tapEnable(tap: tap, enable: false) }
        if let source { CFRunLoopRemoveSource(CFRunLoopGetMain(), source, .commonModes) }
        tap = nil
        source = nil
        isDown = false
    }

    /// Looks at one event. Returns nil to swallow it, or the event to let it through.
    fileprivate func handle(type: CGEventType, event: CGEvent) -> Unmanaged<CGEvent>? {
        switch type {
        case .tapDisabledByTimeout, .tapDisabledByUserInput:
            // macOS switches a tap off if it is slow to answer. Switch it back on.
            if let tap { CGEvent.tapEnable(tap: tap, enable: true) }

        case .flagsChanged:
            let keyCode = Int(event.getIntegerValueField(.keyboardEventKeycode))
            guard keyCode == hotkey.keyCode else { break }
            let pressed = event.flags.contains(hotkey.flag)
            if pressed != isDown {
                isDown = pressed
                _ = onSignal?(pressed ? .hotkeyDown : .hotkeyUp)
            }

        case .keyDown:
            // A held key repeats. Only the first press matters.
            if event.getIntegerValueField(.keyboardEventAutorepeat) != 0 { break }
            let keyCode = Int(event.getIntegerValueField(.keyboardEventKeycode))
            if keyCode == Self.escapeKey {
                if onSignal?(.escape) == true { return nil }
            } else {
                _ = onSignal?(.otherKeyDown)
            }

        default:
            break
        }
        return Unmanaged.passUnretained(event)
    }
}

/// The event tap's entry point. The tap's source is on the main run loop, so this runs on
/// the main thread.
private func hotkeyTapCallback(
    proxy: CGEventTapProxy,
    type: CGEventType,
    event: CGEvent,
    userInfo: UnsafeMutableRawPointer?
) -> Unmanaged<CGEvent>? {
    guard let userInfo else { return Unmanaged.passUnretained(event) }
    let monitor = Unmanaged<HotkeyMonitor>.fromOpaque(userInfo).takeUnretainedValue()
    return monitor.handle(type: type, event: event)
}
```

```swift
import AVFoundation

enum RecorderError: Error {
    case noInput
}

/// Records the default microphone as 16 kHz mono samples, the format the speech engine expects.
final class AudioRecorder {
    /// Called on the main thread with the level of each chunk of audio.
    /// Speech is roughly 0.02 to 0.2.
    var onLevel: ((Float) -> Void)?

    private var engine: AVAudioEngine?
    private var samples: [Int16] = []
    private let lock = NSLock()
    private let outputFormat = AVAudioFormat(
        commonFormat: .pcmFormatInt16,
        sampleRate: 16_000,
        channels: 1,
        interleaved: true
    )!

    func start() throws {
        stop()
        // A fresh engine each time, so a change of microphone between dictations is picked up.
        let engine = AVAudioEngine()
        let input = engine.inputNode
        let inputFormat = input.outputFormat(forBus: 0)
        guard inputFormat.sampleRate > 0, inputFormat.channelCount > 0,
              let converter = AVAudioConverter(from: inputFormat, to: outputFormat) else {
            throw RecorderError.noInput
        }

        lock.lock()
        samples.removeAll(keepingCapacity: true)
        lock.unlock()

        input.installTap(onBus: 0, bufferSize: 1024, format: inputFormat) { [weak self] buffer, _ in
            self?.append(buffer, using: converter)
        }
        engine.prepare()
        try engine.start()
        self.engine = engine
    }

    /// Stops recording and returns everything captured.
    @discardableResult
    func stop() -> [Int16] {
        guard let engine else { return [] }
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        self.engine = nil

        lock.lock()
        defer { lock.unlock() }
        let recorded = samples
        samples = []
        return recorded
    }

    /// Runs on the audio thread. Converts one buffer to 16 kHz mono and stores it.
    private func append(_ buffer: AVAudioPCMBuffer, using converter: AVAudioConverter) {
        let ratio = outputFormat.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * ratio) + 32
        guard let converted = AVAudioPCMBuffer(pcmFormat: outputFormat, frameCapacity: capacity) else { return }

        var supplied = false
        var failure: NSError?
        let status = converter.convert(to: converted, error: &failure) { _, inputStatus in
            if supplied {
                inputStatus.pointee = .noDataNow
                return nil
            }
            supplied = true
            inputStatus.pointee = .haveData
            return buffer
        }
        guard status != .error, let channel = converted.int16ChannelData else { return }

        let count = Int(converted.frameLength)
        guard count > 0 else { return }
        let chunk = UnsafeBufferPointer(start: channel[0], count: count)
        var sumOfSquares: Float = 0
        for sample in chunk {
            let value = Float(sample) / 32768
            sumOfSquares += value * value
        }
        let level = (sumOfSquares / Float(count)).squareRoot()

        lock.lock()
        samples.append(contentsOf: chunk)
        lock.unlock()

        DispatchQueue.main.async { [weak self] in
            self?.onLevel?(level)
        }
    }
}
```

```swift
import AppKit
import ApplicationServices
import Carbon.HIToolbox

/// Where the dictated text is going, captured when the user stops speaking.
struct InsertionTarget {
    var appName: String
    var bundleID: String?
    /// The few characters just before the cursor. Nil when the app does not reveal them.
    var before: String?
    /// True in a password field. Lucid never pastes there.
    var isSecure: Bool
    /// True when the focused control is clearly not somewhere text can go, such as a button.
    var isClearlyNotText: Bool
}

/// Reads the cursor's surroundings and pastes text at the cursor.
enum TextInserter {
    /// Controls that never take typed text. Anything else, including a control the
    /// Accessibility API cannot describe, is given the benefit of the doubt.
    private static let nonTextRoles: Set<String> = [
        "AXButton", "AXCheckBox", "AXRadioButton", "AXMenuItem", "AXMenuBarItem", "AXMenuButton",
        "AXPopUpButton", "AXImage", "AXList", "AXTable", "AXOutline", "AXRow", "AXCell",
        "AXToolbar", "AXTabGroup", "AXSlider", "AXScrollBar", "AXDockItem",
    ]

    private static let transientType = NSPasteboard.PasteboardType("org.nspasteboard.TransientType")

    static func captureTarget() -> InsertionTarget {
        let app = NSWorkspace.shared.frontmostApplication
        var target = InsertionTarget(
            appName: app?.localizedName ?? "Unknown app",
            bundleID: app?.bundleIdentifier,
            before: nil,
            isSecure: IsSecureEventInputEnabled(),
            isClearlyNotText: false
        )

        let system = AXUIElementCreateSystemWide()
        // An app that is busy must not make dictation hang.
        AXUIElementSetMessagingTimeout(system, 0.25)
        var focused: CFTypeRef?
        guard AXUIElementCopyAttributeValue(system, kAXFocusedUIElementAttribute as CFString, &focused) == .success,
              let focused, CFGetTypeID(focused) == AXUIElementGetTypeID() else {
            return target
        }
        let element = focused as! AXUIElement

        if let role = string(element, kAXRoleAttribute) {
            target.isClearlyNotText = nonTextRoles.contains(role)
        }
        if string(element, kAXSubroleAttribute) == "AXSecureTextField" {
            target.isSecure = true
        }
        target.before = textBeforeCursor(element)
        return target
    }

    /// Pastes the text at the cursor. Returns false when it was left on the clipboard instead.
    @discardableResult
    static func insert(_ text: String, into target: InsertionTarget) -> Bool {
        if target.isSecure || target.isClearlyNotText {
            copy(text)
            return false
        }
        paste(text)
        return true
    }

    static func copy(_ text: String) {
        let pasteboard = NSPasteboard.general
        pasteboard.clearContents()
        pasteboard.setString(text, forType: .string)
    }

    private static func string(_ element: AXUIElement, _ attribute: String) -> String? {
        var value: CFTypeRef?
        guard AXUIElementCopyAttributeValue(element, attribute as CFString, &value) == .success else { return nil }
        return value as? String
    }

    /// Up to three characters before the cursor. An empty string means the cursor is at the
    /// very start. Nil means the app does not say.
    private static func textBeforeCursor(_ element: AXUIElement) -> String? {
        var rangeValue: CFTypeRef?
        guard AXUIElementCopyAttributeValue(element, kAXSelectedTextRangeAttribute as CFString, &rangeValue) == .success,
              let rangeValue, CFGetTypeID(rangeValue) == AXValueGetTypeID() else {
            return nil
        }
        var selection = CFRange()
        guard AXValueGetValue(rangeValue as! AXValue, .cfRange, &selection) else { return nil }
        if selection.location <= 0 { return "" }

        let length = min(3, selection.location)
        var wanted = CFRange(location: selection.location - length, length: length)
        guard let parameter = AXValueCreate(.cfRange, &wanted) else { return nil }
        var text: CFTypeRef?
        guard AXUIElementCopyParameterizedAttributeValue(
            element,
            kAXStringForRangeParameterizedAttribute as CFString,
            parameter,
            &text
        ) == .success else { return nil }
        return text as? String
    }

    /// Puts the text on the clipboard, presses Command-V, then restores the clipboard.
    private static func paste(_ text: String) {
        let pasteboard = NSPasteboard.general
        let saved: [[(NSPasteboard.PasteboardType, Data)]] = (pasteboard.pasteboardItems ?? []).map { item in
            item.types.compactMap { type in item.data(forType: type).map { (type, $0) } }
        }

        // Marked transient, so clipboard managers do not record the dictation.
        pasteboard.declareTypes([.string, transientType], owner: nil)
        pasteboard.setString(text, forType: .string)
        pasteboard.setString("", forType: transientType)
        let ours = pasteboard.changeCount

        postCommandV()

        // Give the app time to read the clipboard, then put back what was there.
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.6) {
            // If the count moved, the user copied something else. Leave that alone.
            guard pasteboard.changeCount == ours else { return }
            pasteboard.clearContents()
            let items = saved.map { pairs -> NSPasteboardItem in
                let item = NSPasteboardItem()
                for (type, data) in pairs { item.setData(data, forType: type) }
                return item
            }
            if !items.isEmpty { pasteboard.writeObjects(items) }
        }
    }

    private static func postCommandV() {
        let source = CGEventSource(stateID: .combinedSessionState)
        let keyV: CGKeyCode = 9
        let down = CGEvent(keyboardEventSource: source, virtualKey: keyV, keyDown: true)
        let up = CGEvent(keyboardEventSource: source, virtualKey: keyV, keyDown: false)
        down?.flags = .maskCommand
        up?.flags = .maskCommand
        down?.post(tap: .cghidEventTap)
        up?.post(tap: .cghidEventTap)
    }
}
```

How one dictation runs:

1. Hotkey down. The machine says start. The recorder starts and the pill shows bars.
2. Hotkey up. The machine says stop. The recorder returns its samples, and the cursor's surroundings are read while the user's app still has focus.
3. If the speech gate finds nothing, the pill says "Didn't catch that" and it ends there.
4. Otherwise the pill shows dots while the engines transcribe and clean.
5. The text is pasted, with a leading space if the cursor follows a word. The dictation goes into history with its original transcript.
6. If pasting was not appropriate, the pill says "Copied. Press ⌘V".
7. If the engines failed, the dictation is recorded as failed, with its audio if recordings are kept.

The menu:

- A status line that says what is needed next, or that Lucid is ready.
- A shortcut to the right System Settings pane when a permission is missing.
- Cleanup level and dictation key, each as a submenu.
- Recent dictations. Choosing one copies it. "Copy Last Original" copies the newest uncleaned transcript.

The spec lists "Paste last original". This plan implements copy instead: a menu click can move keyboard focus, and pasting into the wrong place is worse than one extra keystroke.

```swift
import AppKit
import LucidCore
import LucidEngines

/// Connects the keyboard, the microphone, the engines and the document.
@MainActor
final class DictationController {
    private let settings: AppSettings
    private let engines: EngineManager
    private let history: HistoryStore
    private let pill: PillController
    private let recorder = AudioRecorder()
    private var machine = DictationMachine()
    private var ticker: Timer?

    /// Called after a dictation has been added to history.
    var onHistoryChange: (() -> Void)?

    init(settings: AppSettings, engines: EngineManager, history: HistoryStore, pill: PillController) {
        self.settings = settings
        self.engines = engines
        self.history = history
        self.pill = pill
        recorder.onLevel = { [weak self] level in
            self?.pill.setLevel(level)
        }
    }

    /// Handles one keyboard signal. Returns true when the key press should not reach other apps.
    func handle(_ signal: HotkeyMonitor.Signal) -> Bool {
        let wasRecording = machine.isRecording
        switch signal {
        case .hotkeyDown: send(.hotkeyDown)
        case .hotkeyUp: send(.hotkeyUp)
        case .otherKeyDown: send(.otherKeyDown)
        case .escape: send(.escape)
        }
        // Escape cancels a recording, and only then is it kept from the app underneath.
        return signal == .escape && wasRecording
    }

    private func send(_ event: DictationMachine.Event) {
        let actions = machine.handle(event, at: ProcessInfo.processInfo.systemUptime)
        for action in actions { perform(action) }
        updateTicker()
    }

    private func perform(_ action: DictationMachine.Action) {
        switch action {
        case .startRecording:
            startRecording()
        case .stopAndProcess:
            stopAndProcess()
        case .discard:
            recorder.stop()
            pill.hide()
        case .enterHandsFree:
            pill.show(.handsFree)
        case .busy:
            pill.pulse()
        }
    }

    /// The machine needs regular ticks while recording, to time out a tap and to cap the length.
    private func updateTicker() {
        if machine.isRecording {
            guard ticker == nil else { return }
            ticker = Timer.scheduledTimer(withTimeInterval: 0.1, repeats: true) { [weak self] _ in
                MainActor.assumeIsolated { self?.send(.tick) }
            }
        } else {
            ticker?.invalidate()
            ticker = nil
        }
    }

    private func startRecording() {
        guard Permissions.microphone == .authorized else {
            send(.escape)
            pill.flash("Lucid needs microphone access")
            return
        }
        do {
            try recorder.start()
            pill.setLevel(0)
            pill.show(.recording)
        } catch {
            send(.escape)
            pill.flash("No microphone found")
        }
    }

    private func stopAndProcess() {
        let samples = recorder.stop()
        // Read the cursor's surroundings now, while the user's app still has focus.
        let target = TextInserter.captureTarget()
        guard AudioGate.hasSpeech(samples: samples) else {
            pill.flash("Didn't catch that")
            send(.finished)
            return
        }
        pill.show(.processing)
        Task { [weak self] in
            await self?.process(samples: samples, target: target)
            self?.send(.finished)
        }
    }

    private func process(samples: [Int16], target: InsertionTarget) async {
        let wav = WAV.encode(samples: samples)
        let audioSeconds = Double(samples.count) / 16_000
        let dictionary = (try? PersonalDictionary.load(from: AppSettings.dictionaryURL)) ?? .empty
        let context = PipelineContext(
            level: settings.level,
            category: AppCategory.forBundleID(target.bundleID),
            dictionary: dictionary,
            midSentence: InsertionPlanner.isMidSentence(before: target.before)
        )
        let recording = settings.keepRecordings ? wav : nil

        do {
            let outcome = try await engines.dictate(wav: wav, context: context)
            let text = outcome.result.finalText
            guard !text.isEmpty else {
                pill.flash("Didn't catch that")
                return
            }
            let pasted = TextInserter.insert(InsertionPlanner.textToInsert(text, before: target.before), into: target)
            history.add(
                HistoryEntry(
                    date: Date(),
                    appName: target.appName,
                    bundleID: target.bundleID,
                    audioSeconds: audioSeconds,
                    speechMillis: outcome.speechMillis,
                    result: outcome.result,
                    failure: nil
                ),
                wav: recording
            )
            if pasted {
                pill.hide()
            } else {
                pill.flash("Copied. Press ⌘V")
            }
        } catch {
            history.add(
                HistoryEntry(
                    date: Date(),
                    appName: target.appName,
                    bundleID: target.bundleID,
                    audioSeconds: audioSeconds,
                    speechMillis: 0,
                    result: nil,
                    failure: "\(error)"
                ),
                wav: recording
            )
            pill.flash(recording == nil ? "Couldn't transcribe that" : "Couldn't transcribe. Recording kept.", seconds: 3)
        }
        onHistoryChange?()
    }
}
```

```swift
import AppKit
import LucidCore
import LucidEngines

extension CleanupLevel {
    var title: String {
        switch self {
        case .off: return "Off: exactly what you said"
        case .light: return "Light: remove fillers, fix punctuation"
        case .medium: return "Medium: also tighten wording"

@MainActor
final class AppDelegate: NSObject, NSApplicationDelegate, NSMenuDelegate {
    private let settings = AppSettings()
    private let pill = PillController()
    private let history = HistoryStore(directory: EngineConfig.supportDirectory)
    private lazy var engines = EngineManager(level: settings.level)
    private lazy var controller = DictationController(settings: settings, engines: engines, history: history, pill: pill)
    private lazy var hotkeys = HotkeyMonitor(hotkey: settings.hotkey)

    private var statusItem: NSStatusItem?
    private var permissionTimer: Timer?
    private var signalSources: [DispatchSourceSignal] = []
    /// Set when the app is started by a script, so no system dialogs are left on screen.
    private let quiet = CommandLine.arguments.contains("--no-prompts")

    func applicationDidFinishLaunching(_ notification: Notification) {
        if let identifier = Bundle.main.bundleIdentifier,
           NSRunningApplication.runningApplications(withBundleIdentifier: identifier).count > 1 {
            // Lucid is already running. Two copies would both answer the hotkey.
            NSApp.terminate(nil)
            return
        }

        let item = NSStatusBar.system.statusItem(withLength: NSStatusItem.squareLength)
        item.button?.image = NSImage(systemSymbolName: "waveform", accessibilityDescription: "Lucid")
        let menu = NSMenu()
        menu.autoenablesItems = false
        menu.delegate = self
        item.menu = menu
        statusItem = item

        hotkeys.onSignal = { [weak self] signal in
            self?.controller.handle(signal) ?? false
        }
        stopEnginesOnSignals()
        Task { await engines.start() }

        if !quiet {
            Task {
                if Permissions.microphone == .notDetermined { _ = await Permissions.requestMicrophone() }
            }
            if !Permissions.accessibility { Permissions.promptForAccessibility() }
        }
        startHotkeysWhenAllowed()
    }

    func applicationWillTerminate(_ notification: Notification) {
        hotkeys.stop()
        engines.stopNow()
    }

    /// A plain `kill` would skip `applicationWillTerminate` and leave the engines running.
    private func stopEnginesOnSignals() {
        for number in [SIGTERM, SIGINT] {
            signal(number, SIG_IGN)
            let source = DispatchSource.makeSignalSource(signal: number, queue: .main)
            source.setEventHandler { NSApp.terminate(nil) }
            source.resume()
            signalSources.append(source)
        }
    }

    /// The event tap can only be created once Accessibility access is granted, so keep trying.
    private func startHotkeysWhenAllowed() {
        if Permissions.accessibility, hotkeys.start() {
            permissionTimer?.invalidate()
            permissionTimer = nil
            return
        }
        guard permissionTimer == nil else { return }
        permissionTimer = Timer.scheduledTimer(withTimeInterval: 2, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.startHotkeysWhenAllowed() }
        }
    }

    // MARK: Menu

    func menuNeedsUpdate(_ menu: NSMenu) {
        menu.removeAllItems()

        let status = NSMenuItem(title: statusLine, action: nil, keyEquivalent: "")
        status.isEnabled = false
        menu.addItem(status)
        for item in fixItems() { menu.addItem(item) }
        menu.addItem(.separator())

        let levels = CleanupLevel.allCases.map { level -> NSMenuItem in
            let unavailable = level == .medium && !EngineManager.generalModelInstalled
            let item = actionItem(
                unavailable ? "Medium: needs the optional model (see README)" : level.title,
                #selector(chooseLevel(_:))
            )
            item.representedObject = level.rawValue
            item.state = settings.level == level ? .on : .off
            item.isEnabled = !unavailable
            return item
        }
        menu.addItem(submenu("Cleanup", levels))

        let keys = HotkeyChoice.allCases.map { choice -> NSMenuItem in
            let item = actionItem(choice.title, #selector(chooseHotkey(_:)))
            item.representedObject = choice.rawValue
            item.state = settings.hotkey == choice ? .on : .off
            return item
        }
        menu.addItem(submenu("Dictation Key", keys))
        menu.addItem(.separator())

        let recent = history.entries.prefix(8)
        if recent.isEmpty {
            let empty = NSMenuItem(title: "No dictations yet", action: nil, keyEquivalent: "")
            empty.isEnabled = false
            menu.addItem(empty)
        } else {
            let heading = NSMenuItem(title: "Recent (choose one to copy it)", action: nil, keyEquivalent: "")
            heading.isEnabled = false
            menu.addItem(heading)
            for entry in recent {
                let item = actionItem(Self.menuTitle(for: entry), #selector(copyEntry(_:)))
                item.representedObject = entry.id.uuidString
                item.isEnabled = entry.result != nil
                menu.addItem(item)
            }
            menu.addItem(actionItem("Copy Last Original", #selector(copyLastOriginal)))
        }
        menu.addItem(.separator())
        menu.addItem(actionItem("Quit Lucid", #selector(quit), key: "q"))
    }

    private var statusLine: String {
        if !Permissions.accessibility { return "Lucid needs Accessibility access" }
        if !hotkeys.isRunning { return "Restart Lucid to finish setting up" }
        if Permissions.microphone != .authorized { return "Lucid needs microphone access" }
        switch engines.status {
        case .starting: return "Starting the engines…"
        case .setupNeeded: return "Setup needed: run scripts/setup.sh"
        case .failed: return "The engines did not start"
        case .ready: return "Ready. Hold \(settings.hotkey.title) and speak."
        }
    }

    /// Menu items that take the user to whatever is stopping Lucid from working.
    private func fixItems() -> [NSMenuItem] {
        var items: [NSMenuItem] = []
        if !Permissions.accessibility {
            items.append(actionItem("Open Accessibility Settings…", #selector(openAccessibility)))
        } else if !hotkeys.isRunning {
            items.append(actionItem("Restart Lucid", #selector(restart)))
        }
        if Permissions.microphone != .authorized {
            items.append(actionItem("Open Microphone Settings…", #selector(openMicrophone)))
        }
        if settings.hotkey == .fn, Permissions.fnKeyConflicts {
            items.append(actionItem("Fn also triggers a macOS shortcut. Open Keyboard Settings…", #selector(openKeyboard)))
        }
        return items
    }

    private func actionItem(_ title: String, _ action: Selector, key: String = "") -> NSMenuItem {
        let item = NSMenuItem(title: title, action: action, keyEquivalent: key)
        item.target = self
        return item
    }

    private func submenu(_ title: String, _ items: [NSMenuItem]) -> NSMenuItem {
        let parent = NSMenuItem(title: title, action: nil, keyEquivalent: "")
        let menu = NSMenu(title: title)
        menu.autoenablesItems = false
        for item in items { menu.addItem(item) }
        parent.submenu = menu
        return parent
    }

    /// One line for the menu: the start of the text, or the reason it failed.
    private static func menuTitle(for entry: HistoryEntry) -> String {
        guard let result = entry.result else { return "Failed: \(entry.failure ?? "unknown reason")" }
        let line = result.finalText.replacingOccurrences(of: "\n", with: " ")
        return line.count > 60 ? String(line.prefix(57)) + "…" : line
    }

    // MARK: Actions

    @objc private func chooseLevel(_ sender: NSMenuItem) {
        guard let raw = sender.representedObject as? String, let level = CleanupLevel(rawValue: raw) else { return }
        settings.level = level
        Task { await engines.setLevel(level) }
    }

    @objc private func chooseHotkey(_ sender: NSMenuItem) {
        guard let raw = sender.representedObject as? String, let choice = HotkeyChoice(rawValue: raw) else { return }
        settings.hotkey = choice
        hotkeys.hotkey = choice
    }

    @objc private func copyEntry(_ sender: NSMenuItem) {
        guard let raw = sender.representedObject as? String,
              let entry = history.entries.first(where: { $0.id.uuidString == raw }),
              let text = entry.result?.finalText else { return }
        TextInserter.copy(text)
        pill.flash("Copied")
    }

    @objc private func copyLastOriginal() {
        guard let original = history.entries.compactMap({ $0.result?.raw }).first else { return }
        TextInserter.copy(original)
        pill.flash("Original copied")
    }

    @objc private func openAccessibility() { Permissions.openAccessibilitySettings() }
    @objc private func openMicrophone() { Permissions.openMicrophoneSettings() }
    @objc private func openKeyboard() { Permissions.openKeyboardSettings() }

    /// macOS sometimes only lets a newly trusted app create its event tap after a restart.
    @objc private func restart() {
        let task = Process()
        task.executableURL = URL(fileURLWithPath: "/bin/sh")
        // Wait for this copy to quit first, or the new one would see it and quit instead.
        task.arguments = ["-c", "sleep 1; /usr/bin/open \"$0\"", Bundle.main.bundlePath]
        try? task.run()
        NSApp.terminate(nil)
    }

    @objc private func quit() {
        NSApp.terminate(nil)
    }
}
```

Differences from the spec, and why:

- **"Paste last original" is "Copy Last Original".** Explained in Task 4.
- **No microphone picker.** Lucid records the system's default input. Choosing a different device needs CoreAudio code that could not be tested here.
- **Ad-hoc signing only.** The spec proposed a stable local signing identity so that permissions survive rebuilds. Creating one means changing the user's keychain, which should be their decision. Until then, Accessibility access has to be granted again after each rebuild.

Not in this plan, by design: the settings window, the dictionary editor, the history window, onboarding and launch at login (plan 3c).
